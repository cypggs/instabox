# Use cases

> Step-by-step guides for what people build on InstaBox, from running a model's code to CI.

Each guide takes one goal from nothing to a working result, with every command or line of code on the
way. Pick the one closest to what you are building.

## Build with agents

> [card] [Run AI-generated code](https://instabox.sh/docs/use-cases/run-ai-code.md)
>
> Run the code a model writes in a machine of its own, and send the output back to the model.

> [card] [Coding agents](https://instabox.sh/docs/use-cases/coding-agents.md)
>
> Let Claude Code, Codex, or OpenCode work on your repo in a machine, with your keys kept out of it.

> [card] [Computer use](https://instabox.sh/docs/use-cases/computer-use.md)
>
> Give an agent a desktop and a browser to drive, and watch it live or share the screen.

> [card] [Parallel forks](https://instabox.sh/docs/use-cases/parallel-forks.md)
>
> Set up one machine, copy it, try a different approach in each copy, and keep the best.

## Ship and test

> [card] [Preview URLs](https://instabox.sh/docs/use-cases/preview-urls.md)
>
> Run an app in a machine and send someone an HTTPS link to it.

> [card] [CI](https://instabox.sh/docs/use-cases/ci.md)
>
> Run GitHub Actions jobs on fresh machines, or one command from any CI.

> [card] [Android apps](https://instabox.sh/docs/use-cases/android.md)
>
> Install and test an app on Android 14 with adb, and see the phone.

## Connect your tools

> [card] [ADEs](https://instabox.sh/docs/use-cases/ade)
>
> Run cmux, Orca, Paradev, or T3 Code against a machine instead of your laptop.
